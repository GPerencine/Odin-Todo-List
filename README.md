# Restaurant Page

This project is part of the JavaScript course from **The Odin Project**. In this project, I built a restaurant website using JavaScript to dynamically generate and render the page content, with Webpack used to bundle and manage the application.

## Preview

![Restaurant Preview](./src/images/preview.png)

By completing this project, I demonstrated an understanding of DOM manipulation, JavaScript modules, ES6 imports and exports, event handling, dynamic content rendering, Webpack configuration, and project dependency management. I also strengthened my ability to structure JavaScript applications into reusable modules and separate content, logic, and presentation.

This project marked an important step in developing modular JavaScript applications and provided practical experience working with Webpack, dynamic page rendering, and multi-page-like navigation through JavaScript-driven content.
